# Whispers of the Night

<img width="3213" height="1902" alt="IMG_0539" src="https://github.com/user-attachments/assets/6f61a69b-d7fa-46d6-8bcf-33bec302d496" />

A stealth-puzzle horror game built in Unity where Timmy, a 12-year-old boy, 
must navigate a darkness-consumed village armed only with his night lamp 
and the help of fireflies.

🎮 [Play / Download on itch.io](https://alexandermla.itch.io/whispers-of-the-night)

---

## My Role

5-person team project. I was the **sole Unity developer** — responsible for 
all engine work while the rest of the team worked outside Unity.

- All gameplay scripting (C#)
- Scene blocking and layout
- Prefab setup and configuration
- Asset integration (meshes, textures, animations from team members)
- Lighting and atmosphere setup
- UI implementation

---

## Gameplay

- Stealth mechanics — crouch, hide, avoid shadow entities
- Light management — limited lamp battery, strategic on/off
- Firefly system — guided navigation
